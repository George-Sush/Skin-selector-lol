# Skin Selector (Android)

Рандомайзер скинов League of Legends для Android, созданный на Kotlin и Jetpack Compose. Выбирайте чемпиона, настраивайте пул скинов и хром и запускайте случайный выбор.

## Функции

- Каталог из 173 чемпионов, 2 196 обликов и 7 044 хром с русскими и английскими названиями (Riot Data Dragon 16.21.1).
- Режимы выбора: случайный скин, скин или хрома, либо сначала скин и затем хрома.
- Настраиваемый пул чемпионов, скинов и хром; поиск чемпионов и избранное.
- Темы оформления, включая автоматический подбор темы по скину Тимо, и настройка прозрачности фонового сплеш-арта.
- Поддержка локальных изображений для скинов, хром и сплеш-артов.

## Каталог данных

Для Тимо в каталоге заданы 47 хром; для них предусмотрена поддержка локальных изображений. Данные каталога лежат в `app/src/main/assets/champions.json`.

## Возможности

- Выбор персонажа и случайный выбор одного из включённых скинов.
- Режим «Скин и хрома» включает скины и отдельно включённые хромы в один пул.
- Режим «Сначала скин» сначала выбирает скин, а при следующем нажатии выбирает включённую хрому этого скина.
- Можно выключать скины и по отдельности хромы каждого скина.
- В меню настроек выбираются русский или английский язык, цветовая схема, участники пула; список героев можно искать, фильтровать, включать/выключать целиком или оставить включёнными только избранные.
- В настройках можно менять прозрачность сплеш-арта на фоне результата; значение сохраняется между запусками.
- Избранные персонажи сохраняются и отображаются вверху списков; на главном экране есть отдельный поиск для быстрого выбора персонажа.
- Автоматическая тема Тимо подбирается по выпавшему облику (в том числе жёлтая тема для «Пчёлки Тимо») и отключается в настройках.
- Вторая вкладка пока оставлена пустой.

## Добавление изображений

Графические файлы не включены в репозиторий. Добавляйте только изображения, на распространение которых у вас есть права. Их можно хранить в Android assets по следующим путям:

```text
app/src/main/assets/skins/<champion-id>/<skin-id>.png
app/src/main/assets/skins/<champion-id>/<skin-id>/<chroma-id>.png
app/src/main/assets/skins/<champion-id>/splashes/<skin-id>.jpg
```

Например:

```text
app/src/main/assets/skins/ahri/spirit_blossom.png
app/src/main/assets/skins/ahri/spirit_blossom/pearl.png
app/src/main/assets/skins/ahri/splashes/spirit_blossom.jpg
```

Идентификаторы и подписи каталога находятся в `app/src/main/java/ru/skinselector/app/AppData.kt`. Изображения скинов и хром по этим путям автоматически появятся в карточке результата и пуле выбора; для нестандартного имени файла можно задать относительный путь в `assetPath` скина или хромы. Сплеш-арты автоматически загружаются по пути `skins/<champion-id>/splashes/<skin-id>.jpg` (либо по явно заданному `splashAssetPath`) и отображаются полупрозрачным фоном под крупной миниатюрой выпавшего скина.

Миниатюры отображаются в пуле выбора рядом с переключателями, а результат выбора показывается крупнее. Изображения, находящиеся локально в рабочей копии, исключены из Git.

## Сборка

Откройте папку проекта в Android Studio и выполните Gradle Sync. Для сборки нужны Android SDK 35, JDK 17 или новее и Gradle 8.7 (поддерживаемая версия для Android Gradle Plugin 8.6.1).
